# Fonts

Noto Sans Regular and Bold (UI) and Noto Sans Mono Regular (portable console fallback)
are unmodified SIL Open Font License assets. See `LICENSE.txt`.

Source: https://github.com/notofonts/noto-fonts
Pinned revision: `ffebf8c1ee449e544955a7e813c54f9b73848eac`.
Files: `hinted/ttf/NotoSans/NotoSans-Regular.ttf` and `hinted/ttf/NotoSans/NotoSans-Bold.ttf`, plus
`hinted/ttf/NotoSansMono/NotoSansMono-Regular.ttf`.

Windows may use installed Consolas/Courier New for the console; those system
fonts are not redistributed. No renderer falls back to raylib's built-in font.

Noto Sans CJK SC Regular supplies the Japanese, Korean and Chinese menu glyphs.
The OTF and its SIL Open Font License (NotoSansCJK-LICENSE.txt) are the same
unmodified assets used by Dragon Wake, bundled locally for standalone builds.
