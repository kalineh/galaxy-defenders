# Original soundtrack attribution

The original XNA soundtrack is credited to RushJet1. Preserve the existing credits
and metadata in the archived game, recordings and NSF-converted MIDI files.
Some conversions additionally credit Capcom, Rob Hubbard, SEGA and other original
composers; see music_reference_analysis.json for the unmodified metadata excerpts.
The native port now plays newly composed C-synth music; these old recordings are
analysis references, not its playback soundtrack.
